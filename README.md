- `index.html` – Inhalte, SEO-Metadaten, Open Graph und strukturierte Daten

- `script.js` – mobiles Menü, Scroll-Reveals, Jahreszahl und Demo-Kontaktformular
- `impressum.html`, `datenschutz.html` – rechtliche Platzhalterseiten
